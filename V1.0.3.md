## EnQuote — Release Notes

### New Features
- **Cross-manager shared reporting (OneDrive sync).** Supervisor Report Data (`supervisorReportTables`) now automatically exports to a shared OneDrive folder on save/import. Other installs on the same build automatically display this data read-only, with zero manual upload required on their end. Local-only data (never synced to Base44) stays local-only, by design.
- **Unrestricted admin role.** Added a new role that grants full, unrestricted access across the entire application, independent of the existing Submitter/Approver/Admin/Invoicer roles.
- **Hourly Wait Time Summary report.** New report type, importable manually (Report Data → Hourly Wait Time Summary) or via the Auto-Import folder watcher. Automatically converts PST source data to Mountain Time, with correct midnight-rollover handling.
- **Hourly Wait Time Summary widget (Executive Overview).** Replaces the old "Report Data Overview" section. Displays an Incorta-style grid — one column-group per date (Wait Time, # Calls, # ABN Calls, Avg Talktime, ABN %, #Unique Agents), hour-of-day rows, and a Total row per date. Includes its own independent Reporting Period control (Last 7/14/30 Days, All Available History, Custom Range).
- **New "Mackey Purple" color theme.** A sixth theme option alongside Light+, Dark+, Monokai, Solarized Dark, and Solarized Light — vibrant violet accent with a bold dark-violet sidebar and matching tinted surfaces throughout.

### Improvements
- **Simplified report imports.** The manual "Select the tab to import" step is gone — sheet selection now happens automatically on file choice. Hourly Wait Time Summary correctly auto-selects its Detail sheet only (avoiding a prior mismatch with its Pivot sheet); every other report type auto-selects all sheets.
- **Cleaner import dialog.** Removed the "Found X rows across Y columns" summary line and full column-name list for a less cluttered import screen.

### Fixes
- **Vite/PostCSS startup error resolved.** A UTF-8 byte-order-mark (BOM) in `package.json` was causing `Failed to load PostCSS config` on every `npm run desktop:dev` launch. Removed.
- **Corrected garbled (mojibake) characters** appearing across several pages and components — middle dots, en dashes, the "≥" symbol, right arrows, and emoji icons (👤 📋 📧 🚛 📞) were displaying as scrambled character sequences due to an encoding mismatch from an earlier save. Restored to their correct characters across ~22 affected files (Site Flag Manager, Create Quote, Site Quote Tracker, Manager Dashboard, Rejection Progress panels, SLA Reporting, and others). No functional/logic changes — display only.

### Known limitations / follow-ups not yet included in this release
- Weekly/Quarterly email volume & AHT report variants — deferred.
- Git branch workflow for future sessions — deferred, still committing directly to main.
- New unrestricted role must still be manually assigned to specific users in Base44 (this release only teaches the app to recognize the role).
- Left-nav menu visibility for the new unrestricted role has not been updated — the role can access every page directly, but the sidebar may not yet surface links to pages outside the previous role set.
