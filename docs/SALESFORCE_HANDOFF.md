# Salesforce Handoff

The Salesforce team must provide the sandbox My Domain URL, External Client App, OAuth authorization-code flow with PKCE, callback URI, allowed scopes, API version, approved custom object and field API names, Case and Site ID mappings, Product2 and Pricebook strategy, permission sets, file storage strategy, approval workflow decision, and synthetic sandbox test cases.

No Salesforce object API names or credentials are included in this project.
